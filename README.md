# MiniGames

**Live demo:** [https://mini-games-green-three.vercel.app/](https://mini-games-green-three.vercel.app/)

## About

MiniGames is a curated collection of casual browser games spanning multiple genres: puzzles, match, farm, strategy and arcades. Every game loads instantly and runs smoothly right in the browser, making it easy to jump in for a quick session or settle in for longer play.

### Tech Stack

- **TypeScript** — vanilla, no JS frameworks (no React/Vue/Angular)
- **SCSS** — for structured, maintainable styling
- **Vite** — dev server and production bundler

## Getting Started

```bash
# install dependencies
npm install

# start dev server
npm run dev

# build for production
npm run build
```
